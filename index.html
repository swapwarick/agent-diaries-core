Why Not Just Use Redis?

You could build this yourself. Here is what you would have to write and maintain:

Capability DIY with Redis Agent Diaries Core
Atomic Task Ownership Complex Lua scripts + SET NX EX diary.executeOnce()
Crash-Safe Lock Cleanup Manual dead-letter queues & cron jobs Built-in Mutex & TTL
Execution & Result Caching Manual key schemas & custom serialization Automatic T Result Cache

# Examples

Each example is self-contained and runnable in under 5 minutes.

| Example | Description | Run |
|---|---|---|
| [`github-security/`](./github-security/) | 200 agents scanning 50 repos — zero duplicate scans | `npx tsx github-security/index.ts` |
| [`research-swarm/`](./research-swarm/) | 100 research agents, 1 LLM call per topic | `npx tsx research-swarm/index.ts` |
| [`customer-support/`](./customer-support/) | Deduplicate support ticket analysis | `npx tsx customer-support/index.ts` |
| [`langchain-integration/`](./langchain-integration/) | Drop-in with LangChain agents | `npx tsx langchain-integration/index.ts` |
| [`basic/`](./basic/) | Hello world in 10 lines | `npx tsx basic/index.ts` |

## Prerequisites

```bash
npm install @agent-diaries/core tsx
```

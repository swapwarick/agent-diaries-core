CORE ARCHITECTURE

Engineered for High-Scale Agent Architecture

Purpose-built for production agent swarms running on serverless, containers, or edge.

01 / IDEMPOTENCY
⚡

Exactly-Once LLM Execution

Wrap any LLM call or tool invocation in executeOnce(). Guaranteed single execution across distributed clusters, even during network retries.

02 / COORDINATION
🔒

Distributed Swarm Locking

Atomic lock acquiring and automatic lock renewal prevents race conditions when multiple autonomous agents access shared state simultaneously.

03 / MEMORY
🧠

Swarm Memory Deduplication

Automatic payload hashing and vector caching ensure identical prompt context across different sub-agents returns instantly cached results.

04 / PLUGGABLE
🔌

Multi-Provider Adapters

Native adapters for Redis, MongoDB, PostgreSQL, SQLite, and In-Memory storage. Zero vendor lock-in with unified TypeScript contracts.

Why Agent Diaries Core vs Raw Redis?

DEVELOPER QUICK START

Add 1-Line Exactly-Once Protection

Integrate directly into TypeScript, LangChain, CrewAI, or any custom agent loop.

import { AgentDiary } from "@agent-diaries/core";

const diary = new AgentDiary({ agentId: "research-swarm-1" });

// Concurrent agents call executeOnce with the same task key:
const result = await diary.executeOnce(
  "summarize-repo:vercel/next.js",
  async () => {
    return await openai.chat.completions.create({
      model: "gpt-4o",
      messages: [{ role: "user", content: "Summarize latest changes..." }]
    });
  }
);
// Result: Executed EXACTLY ONCE across all 100 swarm workers!
